# Dashboard V28

Dashboard UI en azul y blanco con glassmorphism, gráficos SVG interactivos, gestión de equipo y animaciones suaves.

**Stack:** React 18 · Vite · CSS3 · HTML5 (sin librerías de gráficos)

## Uso

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## Estructura

- `src/data.js`: datos de ejemplo (reemplazar por datos reales)
- `src/components/`: tarjetas, gráfico de área, donut, barras, equipo y actividad
- `src/styles.css`: tokens, glassmorphism, animaciones y responsive
